# 性能测试

本页汇总 Orbien 与同类工具（主要为 `frp`）的性能对比数据，测试环境为本地回环（loopback）网络。

:::note
测试结果受硬件、操作系统、并发数等因素影响，仅供参考。欢迎在 [Issues](https://github.com/orbien-org/orbien/issues) 提交你的测试数据。
:::

## 内存占用

下图为稳定运行状态下的内存占用对比。Orbien 基于 Rust 编写，无 GC 机制，内存使用量更低且曲线更平稳。

![内存占用对比](_img/mem.png)

**结论：**

- Orbien 服务端 + 客户端合计内存占用约 **5–10 MB**
- `frp`（Go 编写）因 GC 机制，内存使用存在周期性波动
- 在内存受限场景（嵌入式设备、低配 VPS）中，Orbien 优势明显
