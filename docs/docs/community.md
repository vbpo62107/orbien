# 社区与贡献

欢迎参与 Orbien 社区！无论是提交 Bug 报告、功能建议，还是贡献代码、完善文档，每一份参与都对项目大有裨益。

## 联系与交流

| 渠道 | 链接 | 说明 |
|------|------|------|
| Discord | [Orbien 社区](https://discord.gg/4dgQjCS3k) | 实时讨论、使用答疑、版本公告 |
| GitHub | [orbien-org](https://github.com/orbien-org) | 源代码、Release、项目动态 |

## 反馈问题

遇到 Bug 或有功能需求，欢迎在 GitHub Issues 提交：

- [提交 Issue](https://github.com/orbien-org/orbien/issues)

提交前请先搜索现有 Issue，避免重复。提交时请尽量包含以下信息：

1. Orbien 版本（`orbien --version`）
2. 操作系统及架构
3. 配置文件（脱敏后）
4. 完整错误日志
5. 复现步骤

## 贡献代码

欢迎通过 Pull Request 参与开发：

- [查看开放的 PR](https://github.com/orbien-org/orbien/pulls)

**贡献流程：**

1. Fork 仓库并创建功能分支（`git checkout -b feat/my-feature`）
2. 提交修改并确保测试通过（`cargo test`）
3. 代码格式化（`cargo fmt`）和静态检查（`cargo clippy`）
4. 推送分支并提交 Pull Request，描述变更内容与动机

## 贡献文档

文档源文件位于仓库 [`docs/docs/`](https://github.com/orbien-org/orbien/tree/main/docs/docs) 目录，使用 Markdown / MDX 编写。本地预览：

```shell
cd docs
pnpm install
pnpm start
```

## 行为准则

请在所有社区渠道中保持友善、包容的交流氛围。我们期待一个开放、互助的技术社区。
